# 냉각기 제어 (안드로이드) — CoolerCommMobile v0.2

냉각기 컨트롤러를 **Modbus TCP(이더넷, 포트 502)** 로 제어하는 안드로이드 앱입니다.
Windows 프로그램(CoolerComm)과 동일한 레지스터맵을 사용합니다.

## 기능
- **모델 선택**: DH ONECYCLE(대호) / DH 3.5(조웰) — 상단 드롭다운
- 컨트롤러 IP/포트/국번 입력 후 연결
- 실시간: 메인온도·서브온도·설정온도(HMI처럼 소수1자리 버림), 운전상태, 제어방식, 알람(이름 표시)
- 운전 / 정지 (DH ONECYCLE = 레지스터 550, DH 3.5 = 레지스터 21)
- **경보 리셋** (DH ONECYCLE = 551, DH 3.5 = 34)
- 설정온도 전송 (모델별 레지스터·배율 자동)
- **PC(폰) 시각 동기화** (DH ONECYCLE = 520~526, DH 3.5 = 120~126, FC06 단일+커밋)
- **입출력 표시**: 입력·출력 상태 비트를 이름 램프로 표시 (ON=색상, OFF=회색)

> ※ DH ONECYCLE 운전/정지·경보리셋·시각동기·출력테스트는 펌웨어의 명령 레지스터
>   (550/551/520~526/530~533)로 동작합니다. 해당 펌웨어가 반영돼 있어야 합니다.
>   (HMI TCP 서버가 코일 FC05를 지원하지 않아 레지스터 방식 사용)

> DH ONECYCLE 은 이더넷(W5500)이 있어 폰(Modbus TCP) 제어에 적합합니다.
> DH 3.5 는 외부 RS485(시리얼)라, 폰에서 쓰려면 컨트롤러에 이더넷이 있어야 합니다.

## 빌드 방법 (Android Studio)
1. **Android Studio(무료)** 설치: https://developer.android.com/studio
2. Android Studio 실행 → **Open** → 이 폴더(`CoolerCommMobile`) 선택.
3. 첫 실행 시 Gradle 동기화가 자동으로 됩니다(인터넷 필요, Gradle 8.7 자동 다운로드).
   - 상단에 "Sync Now" 뜨면 클릭.
4. 폰을 USB로 연결하고 **개발자 옵션 → USB 디버깅** 켠 뒤,
   상단 초록 ▶(Run) 버튼 → 폰 선택 → 설치·실행.
   - 또는 **Build → Build APK** 로 APK를 만들어 폰에 복사·설치.

## 사용
- 같은 WiFi에서는 컨트롤러 IP(예 192.168.1.100) 입력 → 연결.
- 외부(인터넷) 접속은 **Tailscale(무료 VPN)** 권장:
  현장에 항상 켜진 기기 1대 + 폰에 Tailscale 설치 → 앱은 컨트롤러 IP 그대로 사용.
  (공유기 포트 502를 인터넷에 직접 여는 포트포워딩은 보안상 금지)
